## Project state & intent

Arcade Vault: web platform to play games online and compete on a points leaderboard. README specifies a **spec-driven workflow** — use the `/spec` and `/spec-impl` skills (from `Klerith/fernando-skills`) to define and implement features.

The repo is currently the untouched `create-next-app` scaffold: `app/layout.tsx` and `app/page.tsx` still hold default content, App Router, Tailwind CSS v4 (via `@tailwindcss/postcss`), path alias `@/*` → repo root.

## resources.zip — design reference

`resources.zip` (untracked) contains a **standalone HTML/React 18 + Babel prototype** of the full app under `resources/templates/`. It is the visual/UX source of truth to port into the Next.js App Router. Not wired into the build; unzip to read it.

- `Arcade Vault.html` — entry; loads the `.jsx` files in order via Babel standalone
- `app.jsx` — root: hash-based routing + `localStorage` (`av_user`, `av_scores`)
- `data.jsx` — mock `GAMES` catalog
- Screens: `biblioteca` (catalog), `detalle` (game detail), `reproductor` → `GamePlayer`, `auth` (login), `salon` (`HallOfFame` leaderboard); `nav.jsx` = top nav
- Spanish-language UI, retro-arcade aesthetic (Press Start 2P, neon), CSS custom properties in `styles.css`
